# Cấu hình Vercel bản 04

vercel.json giữ nguyên cấu hình static đã xác thực ở bản Vercel trước: outputDirectory=dist, framework=null, buildCommand và installCommand rỗng. Bản này cập nhật mã điều khiển, trang 360° và mô hình; chưa triển khai Vercel thực tế. Sau Deploy cần kiểm tra trang gốc, mô hình, pattern và camera Safari.
